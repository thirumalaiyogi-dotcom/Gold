# Native app prototype (Flutter)

மாதிரி app மட்டும். Test data, உண்மையான login / payment இல்லை. App ID `com.subbulakshmi.stm_proto`, அதனால இப்போ இருக்கும் app-ஓட பக்கத்துலயே install ஆகும்.

- மாதிரி mPIN: `123456`
- Build: `.github/workflows/native-proto.yml`. `native/**`-ல மாற்றம் push செய்தா தானா ஓடும்.
- Android APK: `native-build` branch-ல `stm-native-proto.apk`
- iPhone: `macos` runner-ல code-sign இல்லாம build ஆகுதா என்று மட்டும் சோதனை. iPhone-ல install செய்ய Apple Developer account தேவை.
